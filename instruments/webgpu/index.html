04 / EXECUTION MODEL

How dispatch geometry works

GPU PROGRAMMING
WORKGROUPS256
THREADS / GROUP256
TOTAL INVOCATIONS65,536

A compute shader is dispatched as a grid of workgroups. Each workgroup contains a fixed number of invocations. The global invocation ID identifies an element in the overall workload; bounds checks handle any excess invocations in the final workgroup.

@compute @workgroup_size(256)
fn main(@builtin(global_invocation_id) gid: vec3<u32>) {
  let i = gid.x;
  if (i >= arrayLength(&output)) { return; }
  output[i] = a[i] + b[i];
}

05 / MODEL NOTES

Concepts and caveats

WebGPU
A browser API for modern GPU graphics and general-purpose compute, using WGSL as its shader language.
WGSL
WebGPU Shading Language. The compute kernels in this lab are compiled by the browser's WebGPU implementation.
Workgroup
A group of shader invocations that can cooperate through workgroup memory and barriers.
Dispatch
The command that schedules a grid of workgroups. This lab uses one-dimensional dispatch.
Readback
GPU output is copied to a mappable buffer so JavaScript can inspect and validate the result. Readback adds overhead.

This lab does not request optional device features, create persistent storage, or send workload data over the network. GPU resources are released when the page is closed.
