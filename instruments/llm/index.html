02 / SELF-ATTENTION

Query, key, value

CAUSAL MASKING

Each token projects into queries (Q), keys (K), and values (V). Scaled dot-product attention computes softmax(QKᵀ / √dk + mask) V. The causal mask prevents a position from attending to future tokens.

03 / POSITIONAL INFORMATION

Where order enters

POSITION ENCODING

Self-attention alone is permutation-equivariant. Transformers therefore need a mechanism to represent token position. Compare illustrative sinusoidal encodings with rotary position embeddings (RoPE).

POSITION VECTOR / FIRST 16 CHANNELS

Sinusoidal encoding

A deterministic vector is added to token embeddings. Different frequencies encode different positional scales.

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

04 / INFERENCE MEMORY

KV-cache calculator

DECODE-TIME STATE

Autoregressive decoding can reuse previously computed keys and values instead of recomputing attention projections for the entire prefix. The cache grows with batch size, layer count, sequence length, KV heads, head dimension, and element size.

KV bytes = 2 × layers × batch × sequence × KV heads × head dimension × bytes / element
ESTIMATED KV CACHE2.25 GiB2 × 24 × 1 × 4096 × 12 × 64 × 2 bytes

Estimate scales linearly with context length and batch size.

05 / SPARSE EXPERT MODELS

Mixture-of-experts routing

TOP-K GATING

A learned router scores experts for each token. Top-k routing activates only a subset of expert feed-forward networks per token. Sparse activation can increase total parameter capacity without activating every expert on every token.

06 / CONCEPTS & LIMITATIONS

Reading the model

Multi-head attention
Several learned projection subspaces attend in parallel. This visualization samples synthetic scores; it does not load trained attention weights.
Grouped-query attention (GQA)
Multiple query heads share each key/value head. When KV heads are fewer than query heads, the KV cache is reduced proportionally.
KV cache
Stores keys and values for prior tokens during autoregressive inference. The estimate excludes model weights, activations, quantization metadata, fragmentation, and implementation-specific overhead.
Mixture of experts (MoE)
A router dispatches tokens to selected expert networks. Real systems also require dispatch, combine, capacity, load-balancing, and distributed communication mechanisms.

This explorer is an architectural teaching aid, not a model profiler or benchmark. Values are illustrative and do not predict the performance or memory behavior of a specific deployed model.
